# KeyClick — 键盘快捷键代替鼠标点击

一个**通用**的屏幕快捷键工具：把键盘**单键或组合键**绑定到页面上的坐标，按下即在指定位置触发鼠标点击，无需移动鼠标。一个快捷键可以绑定**一串**位置，按下后按顺序连续点击（间隔可调）。

绑定的是**坐标**而不是某个 DOM 元素，所以它对页面结构没有要求：普通网页能用，把整个 UI 渲染进单个 `<canvas>` 的页面（网页游戏、H5 应用、白板/编辑器这类）也能用——只要点击能落在页面上，就能被快捷键复现。

点击以**合成鼠标事件**派发（`pointerover → pointermove → pointerdown → 按住 → pointerup → click`），事件的 `isTrusted === false`。这样做的代价与收益见下方「为什么不用 CDP」。

---

## 安装

1. 打开 `chrome://extensions`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本目录（含 `manifest.json` 的那一层）
4. 图标生成（首次或修改图标后）：`node tools/gen-icons.mjs`

> 若 `assets/icons/` 已存在则无需重新生成。扩展只需 `storage` 权限，不申请 `debugger`，因此不会出现「已开始调试此浏览器」信息栏。

## 快速上手

1. 打开要绑定快捷键的页面，右下角会出现 KeyClick 悬浮图标，点击展开面板。
2. 点 **＋ 录制快捷键（连点多个位置即为顺序点击组）** → 面板自动收起，出现十字准星。
3. **依次点击**页面上要绑定的位置。默认情况下点击会**照常生效**，所以可以先真实操作页面切到别的界面，再点下一个位置——多界面流程正是这样录的。不想让页面收到录制期间的点击，就把设置里的**「录制时点击照常生效」**关掉：点击被扩展吞掉，页面不会响应，只用来取坐标。点一个就是单点快捷键，连点多个就是**按顺序连续点击的组**；每次点击都会出现红色编号预览点，**右键撤销上一个点**（右键在两种模式下都始终被扩展吃掉，不会传给页面，也不弹系统菜单）。
4. **按下**要绑定的按键：单键（如 `H`）或组合键（如 `Shift + H`、`Ctrl + Shift + 1`）。
5. **再按一次**同一按键完成自检（确认浏览器真的能把它送达页面）。
6. 之后随时按该键即可触发。`Escape` 可在录制中取消。

绑定成功后，每个触发点上会出现一个**持久标记浮层**：圆形标识**正中标在点击位置上**，快捷键符号写在圆内（`H`、`⇧H`、`⌃⇧1`）；组的每个点各有一个标识并带序号（`1 ⇧H`、`2 ⇧H`、`3 ⇧H`），一眼能看出点击顺序。标签较长时圆形会自动长成胶囊。整层 `pointer-events: none`，不影响鼠标正常点击；开关在设置的**「显示坐标标记浮层」**复选框。

面板还提供：

- **方案**：切换 / 新建 / 改名 / 删除。切换成功后提示「已切换到方案「X」，N 条快捷键」，失败则提示原因并把下拉框弹回仍然生效的方案；新建的方案是**空的**，快捷键需要在新方案里重新录制，这样两个方案永远不会看起来一模一样
- **规则列表**：查看当前方案的规则（单点显示坐标——落在 canvas 上的点是归一化百分比，其余是视口像素；组显示「N 个点」）/ 修改组的统一间隔 / 展开步骤为每一步单独设间隔 / 测试点击 / 改名 / 删除。列表按**最新添加在上**排序；标题右侧的按钮可以把整个列表**收起**（按钮变成「展开列表（N）」），收起后不用滚动就能看到下面的设置
- **导出设置 / 导入设置**：JSON 文件，导入时可选「覆盖已有」或「跳过已有」；导入文件的 `version` 必须与当前版本一致，否则会被明确拒绝
- **设置**：总开关、输入框内不触发、录制时点击照常生效、显示坐标标记浮层、按住时长、浮现透明度、浮现时长

工具栏图标点击可全局启停（停用时会显示 `OFF` 角标）。

## 组（顺序连点）

一条规则携带一串点，按下快捷键后按录制顺序依次点击，节奏是**按下 → 按住（设置的按住时长）→ 抬起 → 等间隔 → 下一个点**。

- **统一间隔**：每条组规则一个默认值，规则行里的「统一间隔」输入框即改即存，范围 0–10000 ms，新录制的组默认 120 ms。单点规则不显示该输入。
- **逐步间隔**：点「展开步骤（N）」列出每一步的坐标，除最后一步外每步都有「等待 N ms」输入框——它表示**本步点击后到下一步点击前**的等待。改动即存为该步的 `gapMs` 覆盖（输入框会标成紫色），**留空或点「重置」即回到统一间隔**。跨界面的流程就是靠它：切换界面那一步设长一点（例如 1500 ms），同界面内的连点设短一点。
- **跨界面录制**：录制时点击默认照常传给页面，因此可以真的操作页面切到下一个界面、再继续点下一个位置；不希望页面收到这些点击时，关掉设置里的「录制时点击照常生效」。
- **播放中再按同一快捷键 = 取消剩余步骤**，不会重播也不会排队，并提示「已取消剩余点击」。已经开始的那一次按下/抬起不会被打断。
- **长按不会误取消**：按住不放产生的自动重复按键被忽略。
- **切到后台自动停止**：标签页不可见时取消所有正在播放的组，避免看不见的页面还在被连点。
- 某个点解析失败（例如 canvas 消失）只跳过该点并给出警告，不中断整组。
- **播放不会等待界面加载**：只按设定的间隔点击，不判断画面是否已经切换到下一步需要的界面。

## 坐标模型

录制时每个点都会存下**视口像素坐标**（`x` / `y`）；如果点击正好落在某个 `<canvas>` 上，还会额外存下**相对该 canvas 矩形的归一化比例**（`nx` / `ny`）与画布指纹。触发时优先用归一化比例配合当前 canvas 的 `getBoundingClientRect()` 反算视口像素，因此：

- 页面滚动会被自动抵消；
- 改变浏览器窗口大小后，只要画布只是整体缩放，仍会命中同一相对位置。

点击没有落在 canvas 上的点（普通网页的点全是这种）只带视口像素坐标，触发时**直接按原始坐标点击**，不弹警告——这是正常路径。代价是这类点对布局变化更敏感：元素被挪走或页面重新排版，就会点空。

自适应画布（等比缩放、按宽铺满、按高铺满之类策略）在不同宽高比下往往会**重新排布** UI，归一化坐标也会跟着偏；DOM 布局的响应式改版同理。这正是**方案**存在的理由：为「窗口化 16:9」「最大化 21:9」等不同布局各建一个方案，切换方案即切换整套坐标，快捷键只在当前方案内生效。

## 为什么不用 CDP

`chrome.debugger` + `Input.dispatchMouseEvent` 能派发 `isTrusted === true` 的真实点击，但 attach 后标签页顶部**必然**出现「KeyClick 已开始调试此浏览器」信息栏，且无法用代码消除。实测下来普通网页与把 UI 全画进 canvas 的页面都能正确响应合成鼠标事件，因此本版移除了整条调试通路：没有信息栏，没有 `debugger` 权限，触发路径更短。

若将来遇到校验 `isTrusted` 的页面，可从 git 历史恢复 CDP 实现——届时浏览器会显示调试信息栏，这是平台的安全提示，属于预期行为。

## 已知限制

| 限制 | 说明 |
|---|---|
| **事件非可信** | 合成事件 `isTrusted === false`。校验该字段的页面会忽略点击 |
| **焦点必须在页面内** | 焦点在地址栏、书签栏、DevTools 或其他窗口时快捷键不触发。Web 平台限制 |
| **只发鼠标事件** | 只监听 `touchstart` / `touchend` 的页面（部分移动端适配页面）不会响应。当前版本不派发 touch |
| **单键会拦截页面原有行为** | 绑定 `H` 后，该按键不再传给页面自身逻辑（`preventDefault` + `stopPropagation`）。输入框内可通过「输入框内不触发」豁免 |
| **不支持 iframe** | 目标页面必须在顶层打开。在 iframe 内会给出提示 |
| **浏览器保留键不可用** | `Ctrl+T/W/N`、`Ctrl+1..9`、`F5`、`F11`、`Escape` 等永不送达页面或被本扩展占用，录制时会被拦截；漏网的由自检兜底 |
| **绑的是坐标，不是元素** | 页面重排或元素挪位后，坐标就指不到原来的控件。归一化到 canvas 的点扛得住整体缩放，扛不住重新排布；触发时发现窗口尺寸或屏幕缩放变了会给出警告，此时请切换方案或重新录制 |
| **不兼容旧版数据** | v3 起规则携带 `steps`，本机已录制的 v1/v2 数据与旧版导出的 JSON 都不再被读取（导入会明确报版本不支持），需要重新录制 |
| **`chrome://` / 应用商店 / PDF** | 内容脚本不注入，无法使用 |

## 使用须知

KeyClick 是一个通用的**坐标点击自动化**工具，用途是把你自己重复执行的鼠标操作变成快捷键。使用前请确认：

- 只在你**自己拥有或已获得授权**的页面与账号上使用，并遵守目标站点的服务条款和适用的法律法规；
- 不少站点明确禁止自动化操作，违反可能导致账号受限等后果，请你自行评估并承担相应风险；
- 自动化点击不会等待界面加载、也不判断当前画面是否符合预期，**执行结果需要你自己确认**，不建议在无人值守的情况下长时间运行；
- 本项目按现状（as-is）提供，不含任何明示或默示的担保，使用产生的后果由使用者自行承担。

{
  "version": 3,
  "settings": { "enabled": true, "holdMs": 50, "skipInInput": true, "recordPassthrough": true,
                "showMarkers": true, "hintOpacity": 0.3, "hintDurationMs": 900 },
  "sites": {
    "https://example.com": {
      "enabled": true,
      "activeScheme": "默认",
      "schemes": {
        "默认": { "rules": [ { "id": "r_x", "name": "", "shortcut": { "code": "KeyH", "key": "h",
                   "ctrl": false, "alt": false, "shift": false, "meta": false, "label": "H" },
                   "steps": [
                     { "nx": 0.5, "ny": 0.5, "x": 640, "y": 360,
                       "canvas": { "index": 0, "id": "", "cls": "", "w": 1280, "h": 720 } },
                     { "nx": 0.8, "ny": 0.6, "x": 1024, "y": 432,
                       "canvas": { "index": 0, "id": "", "cls": "", "w": 1280, "h": 720 },
                       "gapMs": 1500 }
                   ],
                   "intervalMs": 120,
                   "button": "left", "clickCount": 1,
                   "env": { "vw": 1280, "vh": 720, "dpr": 1 }, "createdAt": "..." } ] },
        "大屏": { "rules": [] }
      }
    }
  }
}
```

单点快捷键就是**只有一个步骤的组**，结构完全一致。`intervalMs` 是组内相邻两次点击的**统一间隔**；步骤可选带 `gapMs` **覆盖**它，含义是「本步点击后到下一步点击前的等待」，缺省或非法时回落到 `intervalMs`。最后一步之后没有点击，它的间隔不参与播放。`env` 仍在规则级——同一次录制里窗口环境是相同的。

点击没有落在 canvas 上的步骤长这样：`{ "nx": null, "ny": null, "x": 512, "y": 384, "canvas": null }`，播放时直接按 `x` / `y` 的视口像素点击。

**不做旧数据迁移**：v1（站点直接挂 `rules`）与 v2（规则直接挂 `nx/ny/x/y`）的本地数据在读取时会被丢弃，旧版导出的 JSON 会在导入时被拒绝，都需要重新录制。

manifest.json                 MV3 清单（权限仅 storage）
src/shared/protocol.js        存储 key / 版本号 / 默认设置 / 默认方案名 / 默认步间隔
src/background/service-worker.js   工具栏图标全局启停与角标
src/content/00-namespace.js   共享命名空间与全局 UI 状态
src/content/core/hotkeys.js   按键规范化、符号化、保留键黑名单、匹配、逐步标签
src/content/core/store.js     chrome.storage.local 读写 + 缓存 + 方案模型 + 规则形状约束
src/content/core/clicker.js   canvas 定位、归一化坐标反算、合成点击派发、组播放与取消
src/content/core/transfer.js  JSON 导出 / 导入 / 校验 / 合并策略
src/content/ui/styles.js      Shadow DOM 样式
src/content/ui/hint.js        触发浮现层、toast、录制预览点（pointer-events: none）
src/content/ui/markers.js     持久快捷键标记浮层，按步骤渲染圆内标识（pointer-events: none）
src/content/ui/recorder.js    录制：连点成组 → 按键 → 自检
src/content/ui/panel.js       悬浮图标 + 菜单面板（方案 / 规则 / 导入导出 / 设置）
src/content/main.js           装配、keydown 路由、iframe 检测
tools/gen-icons.mjs           手写 PNG 编码器生成图标
tools/smoke-content.mjs       Node 侧内容脚本冒烟测试
tools/verify-inject.mjs       有头 Chrome 注入检查
test/demo.html                自测页
LICENSE                       MIT 许可证
```
