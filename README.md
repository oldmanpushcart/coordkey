# KeyClick

> 把键盘快捷键绑定到屏幕坐标：按下单键或组合键，就在你录下的位置触发鼠标点击。
> Bind keyboard shortcuts to screen coordinates — one keypress replays one click, or a whole sequence of them.

## 它解决什么问题

同一页面上每天重复点同样的按钮？把 UI 全画进 canvas 的应用里鼠标够着点很别扭？一串跨界面的固定操作要点六七下？

KeyClick 让你**录一次位置，之后只按键盘**：

- 点一个位置 = **单点快捷键**；
- 连点一串位置 = **顺序连点组**，间隔可调、可逐步覆盖；
- 窗口尺寸或布局不同 = 不同**方案**，下拉框一键切换。

它绑的是**坐标**而不是某个 DOM 元素，所以对页面结构没有要求：普通网页能用，把整个 UI 渲染进单个 `<canvas>` 的页面（网页游戏、H5 应用、白板 / 编辑器这类）也能用——只要点击能落在页面上，就能被快捷键复现。

## 特性

- **单键或组合键**触发（`H`、`Shift + H`、`Ctrl + Shift + 1` …）；浏览器保留键在录制时就被拦截
- **顺序连点组**：一次录制多个位置，按下后按序点击；统一间隔 + 每步可选的逐步间隔
- **方案**：同一站点下多套坐标互不干扰，切换即整套生效
- **持久标记浮层**：每个触发点画一个圆，符号写在圆内（`H`、`⇧H`），组的每个点带序号（`1 ⇧H`）；不吞鼠标点击
- **录制穿透开关**：录制时点击可照常传给页面（跨界面流程正是这样录的），也可只取坐标、不让页面响应
- **导入 / 导出** JSON，导入可选「覆盖已有」或「跳过已有」
- **零构建**：全部是经典脚本，克隆后直接加载，不需要 `npm install`
- **权限最小化**：只申请 `storage`；不使用 `chrome.debugger`，因此不会出现「已开始调试此浏览器」信息栏
- 面板与浮层装在 Shadow DOM 里，不被页面样式污染，也不影响页面布局

## 安装

1. 打开 `chrome://extensions`
2. 右上角开启**开发者模式**
3. 点**加载已解压的扩展程序**，选择本仓库根目录（含 `manifest.json` 的那一层）

无需构建、无需依赖，图标已随仓库提供。若要重新生成图标：`node tools/gen-icons.mjs`。

## 快速上手

1. 打开要绑定的页面，右下角出现 KeyClick 悬浮图标，点击展开面板。
2. 点**「＋ 录制快捷键」**，面板自动收起并出现十字准星。
3. **依次点击**要绑定的位置：点一个是单点，连点多个就是组；每次点击出现红色编号预览点，**右键撤销上一个点**，`Escape` 取消本次录制。
4. **按下**要绑定的按键（单键或组合键）。
5. **再按一次**同一按键完成自检（确认浏览器真的能把它送达页面）。
6. 之后随时按该键即触发；每次触发会在点击位置浮现一次反馈标签。

默认情况下录制期间的点击**照常生效**，所以可以先真实操作页面切到下一个界面、再点下一个位置；不希望页面收到这些点击时，关掉设置里的**「录制时点击照常生效」**——点击被扩展吞掉，只用来取坐标。

## 核心概念

### 组（顺序连点）

一条规则携带一串点，按下后按录制顺序依次点击，节奏是**按下 → 按住（设置的按住时长）→ 抬起 → 等间隔 → 下一个点**。

- **统一间隔**：每条组规则一个默认值（新录制的组默认 120 ms），规则行内即改即存；
- **逐步间隔**：「展开步骤（N）」里除最后一步外每步都有「等待 N ms」——含义是**本步点击后到下一步点击前**的等待。改动后输入框标紫，留空或点「重置」回到统一间隔。跨界面流程靠它：切界面那一步设长（如 1500 ms），同界面连点设短；
- **播放中再按同一快捷键 = 取消剩余步骤**，不重播也不排队；长按产生的自动重复按键被忽略，不会误取消；
- 标签页切到后台时自动取消所有播放中的组，不在看不见的页面里继续连点；
- 某个点解析失败（例如 canvas 消失）只跳过该点并警告，不中断整组；
- **播放不等待界面加载**：只按设定的间隔点击，不判断画面是否已就绪。

### 方案

规则按 `location.origin` 分站存储，站内再分方案。自适应画布或响应式布局在不同宽高比下会**重新排布** UI，同一套坐标不可能通吃所有窗口形态——为「窗口化 16:9」「最大化 21:9」这类布局各建一个方案，切换方案即切换整套坐标。新建的方案是**空的**，快捷键需要在新方案里重新录制。

### 标记浮层

绑定成功后每个触发点上有一个圆形标识，**正中标在点击位置上**：单点写符号（`H`、`⇧H`、`⌃1`），组的每个点写「序号 + 符号」（`1 ⇧H`、`2 ⇧H`）；标签较长时圆形自动长成胶囊。整层 `pointer-events: none`，不影响鼠标正常点击；开关在设置的**「显示坐标标记浮层」**。

### 坐标如何跟随页面

- 点击落在 `<canvas>` 上的点：额外存下相对画布矩形的**归一化比例**与画布指纹，触发时按当前 `getBoundingClientRect()` 反算视口像素——页面滚动自动抵消，窗口缩放后仍命中同一相对位置；
- 没落在 canvas 上的点（普通网页全是这种）：只存视口像素，触发时**直接按原始坐标点击**，这是正常路径、不弹警告；代价是对重排更敏感，元素挪位就会点空；
- 触发时若发现窗口尺寸或屏幕缩放与录制时不同，会给出警告，此时请切换方案或重新录制。

## 面板速览

| 区域 | 能做什么 |
|---|---|
| **方案** | 切换 / 新建（空方案）/ 改名 / 删除。切换成功提示「已切换到方案「X」，N 条快捷键」，失败提示原因并把下拉框弹回仍生效的方案 |
| **规则列表** | 最新录制的排在最上；查看坐标（canvas 点显示归一化百分比，其余显示视口像素）；改统一间隔；展开步骤改逐步间隔；测试点击；改名；删除；整列表可收起 |
| **导入 / 导出** | JSON 文件；导入可选「覆盖已有」或「跳过已有」；文件版本与当前版本不符会被明确拒绝 |
| **设置** | 总开关、输入框内不触发、录制时点击照常生效、显示坐标标记浮层、按住时长、浮现透明度、浮现时长 |

工具栏图标点击可全局启停（停用时显示 `OFF` 角标）。

## 已知限制

| 限制 | 说明 |
|---|---|
| **事件非可信** | 合成事件 `isTrusted === false`。校验该字段的页面会忽略点击 |
| **焦点必须在页面内** | 焦点在地址栏、书签栏、DevTools 或其他窗口时快捷键不触发。Web 平台限制 |
| **只发鼠标事件** | 只监听 `touchstart` / `touchend` 的页面（部分移动端适配页面）不会响应。当前版本不派发 touch |
| **单键会拦截页面原有行为** | 绑定 `H` 后，该按键不再传给页面自身逻辑（`preventDefault` + `stopPropagation`）。输入框内可通过「输入框内不触发」豁免 |
| **不支持 iframe** | 目标页面必须在顶层打开。在 iframe 内会给出提示 |
| **浏览器保留键不可用** | `Ctrl+T/W/N`、`Ctrl+1..9`、`F5`、`F11`、`Escape` 等永不送达页面或被本扩展占用，录制时会被拦截；漏网的由自检兜底 |
| **绑的是坐标，不是元素** | 页面重排或元素挪位后，坐标就指不到原来的控件。归一化到 canvas 的点扛得住整体缩放，扛不住重新排布 |
| **不兼容旧版数据** | v3 起规则携带 `steps`，本机已录制的 v1/v2 数据与旧版导出的 JSON 都不再被读取（导入会明确报版本不支持），需要重新录制 |
| **`chrome://` / 应用商店 / PDF** | 内容脚本不注入，无法使用 |

## 使用须知

KeyClick 是一个通用的**坐标点击自动化**工具，用途是把你自己重复执行的鼠标操作变成快捷键。使用前请确认：

- 只在你**自己拥有或已获得授权**的页面与账号上使用，并遵守目标站点的服务条款和适用的法律法规；
- 不少站点明确禁止自动化操作，违反可能导致账号受限等后果，请你自行评估并承担相应风险；
- 自动化点击不会等待界面加载、也不判断当前画面是否符合预期，**执行结果需要你自己确认**，不建议在无人值守的情况下长时间运行；
- 本项目按现状（as-is）提供，不含任何明示或默示的担保，使用产生的后果由使用者自行承担。

## 为什么是合成事件而不是 CDP

`chrome.debugger` + `Input.dispatchMouseEvent` 能派发 `isTrusted === true` 的真实点击，但 attach 后标签页顶部**必然**出现「KeyClick 已开始调试此浏览器」信息栏，且无法用代码消除。实测普通网页与把 UI 全画进 canvas 的页面都能正确响应合成鼠标事件，因此本版移除了整条调试通路：没有信息栏，没有 `debugger` 权限，触发路径更短。

若将来遇到校验 `isTrusted` 的页面，可从 git 历史恢复 CDP 实现——届时浏览器会显示调试信息栏，这是平台的安全提示，属于预期行为。

## 开发

零构建：内容脚本按 `manifest.json` 的 `js` 数组顺序加载，共享 `self.KEYCLICK` 命名空间；面板与浮层各自装在闭包 Shadow DOM 里。

```bash
node tools/gen-icons.mjs        # 重新生成图标（手写 PNG 编码器，无依赖）
node tools/smoke-content.mjs    # Node 侧冒烟：按键规范化与保留键、规则形状约束、方案增删切换、
                                # 组播放时序与取消语义、坐标两条解析路径、录制穿透开关
node tools/verify-inject.mjs    # 连接已手动加载扩展的 Chrome，检查注入与控制台报错
```

- 存储结构与版本策略：[docs/storage.md](docs/storage.md)
- 真实浏览器验收清单：[docs/manual-checklist.md](docs/manual-checklist.md)（含「Chrome stable 静默忽略 `--load-extension`，端到端只能手动加载」的环境说明）
