# 手动验收清单

自动化只能覆盖一部分（见 `tools/smoke-content.mjs` 的说明），以下项目请在真实浏览器执行。

> **为什么必须手动**：Chrome 152.0.7977.76 stable（2026-09-09 复测）会**静默忽略** `--load-extension`，有头与 `--headless` 都一样——启动后 `<user-data-dir>\Default\Secure Preferences` 的 `extensions.settings` 里只有 Chrome 自带组件扩展，本项目扩展根本没登记，`/json/list` 也看不到它的 Service Worker。推测是 Chrome 137 起 stable 渠道移除了该开关。因此**不要**尝试用自动化启动做端到端验证，请在 `chrome://extensions` 手动加载 / 重新加载。

## 触发与坐标

- [ ] 在任意**没有 canvas** 的普通网页上录制单键并触发：点击落在录制时的视口位置，且**不弹**坐标警告（原始坐标是正常路径，不是降级）
- [ ] 在 `test/demo.html` 的 canvas 上录制单键 `H` 只点一个位置，刷新后按键，`canvas 点击计数` +1（日志会显示 `isTrusted=false`，这是预期的）
- [ ] 标记为**圆内** `H`，圆直径约 26px，标识不再跑到圆外；用真实鼠标点击标记所在位置，仍能正常命中 canvas（浮层不吞点击）
- [ ] 改变窗口大小，canvas 页面上的标记随画布移动（普通网页录的点保持在原视口像素位置）；设置里关闭「显示坐标标记浮层」后标记消失，打开后恢复
- [ ] 录制「悬停展开菜单」下的菜单项 A，按键后 `hover 菜单点击` +1（验证 `pointerover/mousemove` 先行）
- [ ] 焦点放在输入框时按已绑定的单键，不触发且能正常输入
- [ ] 录制 `Ctrl+Digit1` 等保留键，被当场拦截；录制时不点任何位置直接按键，提示「请先点击要绑定的位置」

## 录制

- [ ] 录制 `Shift + H` 时连点 3 个位置：每次点击都出现红色编号预览点，右键能撤销上一点且不弹系统菜单；保存后三个标记依次为 `1 ⇧H`、`2 ⇧H`、`3 ⇧H`
- [ ] 「录制时点击照常生效」开启（默认）时录制：左键点击**真实生效**，`canvas 点击计数` 每点一次 +1、日志为 `isTrusted=true`；右键撤销时计数不动、也不弹系统菜单
- [ ] 关掉「录制时点击照常生效」再录制：预览点照常出现（坐标仍被记录），但 `canvas 点击计数` **不再增加**，录制提示变成「点击不会传给页面」；右键撤销依旧不弹系统菜单
- [ ] 录制途中改这个开关：点悬浮图标重新打开面板勾选/取消，下一次点击立即按新模式处理（无需重新开始录制）
- [ ] 点击面板外区域，面板收起

## 组播放与间隔

- [ ] 按 `Shift + H` → 点击计数 +3，日志三条 `isTrusted=false`，间隔约为设定值，每步各有一次浮现反馈（标签形如 `2/3 Shift + H`）
- [ ] 规则行里把间隔从 120 改成 600 → 再按一次，节奏明显变慢
- [ ] 点「展开步骤（N）」→ 每一步列出坐标，除最后一步外都有「等待 N ms」输入框
- [ ] 把第 1 步的等待改成 800 → 播放时第 1、2 次点击之间明显变慢（demo 页日志的 `Δ` 约 800ms），第 2、3 次之间仍是统一间隔；该输入框标为紫色并出现「重置」
- [ ] 点「重置」或清空该输入框 → 该步回到统一间隔，紫色标记与「重置」按钮消失
- [ ] 改完间隔 / 展开步骤后面板重渲染，展开状态保持不变
- [ ] 播放途中再按一次 `Shift + H` → 剩余步骤停止，出现「已取消剩余点击」
- [ ] **长按** `Shift + H` 不触发取消，正常播完整组
- [ ] 播放途中切到别的标签页 → 组停止，不在后台继续点击

## 方案与列表

- [ ] 新建方案「大屏」→ 规则列表为空并提示「当前方案还没有绑定任何快捷键，点上方「录制快捷键」开始录入」；在「大屏」里录一条 → 切回「默认」看不到这条规则
- [ ] 列表收起时新建空方案 → 仍能看到「展开列表」按钮，点它回到空列表（不会被卡在收起态）
- [ ] 同一按键在两个方案里绑定不同坐标，切换方案后触发命中不同位置
- [ ] 切换方案时出现「已切换到方案「X」，N 条快捷键」提示，标题、规则列表、标记浮层与按键触发全部跟随新方案
- [ ] 规则列表里最新录制的排在最上；点标题右侧「收起列表」→ 列表隐藏、按钮变「展开列表（N）」、设置区不用滚动即可见；再点恢复；切方案或改间隔后收起状态保持
- [ ] 只剩一个方案时「删除」按钮为禁用态

## 导入导出

- [ ] 导出 → 删除规则 → 导入 → 规则恢复；再测「跳过已有」不覆盖
- [ ] 导入改动前导出的 v2 JSON → 得到「不支持的配置版本 2（当前为 3）」提示，而不是静默清空
